# 起名agent
## 输入
- 姓
- 孩子的生辰八字（阳历年月日几点几分）
- 出生地
- 性别

## 输出
输出3个候选名字，并且解释下为啥要这么取，以及具体的意思

## 要求
- 符合五行
- 男孩从楚辞里面取
- 女孩从诗经里面取
- 积极向上，无不好的谐音
- 不包含姓1～3个字，大多数情况以2个字为主，3个字一般不用

## 过程
- 根据孩子的生辰八字（年月日几点几分）以及出生地（用于计算真太阳时），计算出五行八字
- 根据五行八字，分析出名字里面喜什么和忌用什么
- 根据男孩还是女孩，分别从楚辞或诗经里面找符合五行的词，可以找出一定的候选，比如10个（根据情况可能需要更多）
- 依次验证每个名字，去掉不符合要求的，然后选出3个符合要求的名字
